# Отчёт по ЛР5: Форма и список в памяти

## 1. Результаты проверки

| Проверка | Что делаю | Факт |
|----------|-----------|------|
| **Успех** | Ввожу тему ≥ 5 символов, номер проекта > 0, описание ≥ 10 символов | Строка со статусом «Новая» (New) появилась в конце таблицы |
| **Отказ** | Ввожу тему `abc` (3 символа) и нажимаю «Создать» | Появилась красная ошибка «Тема: от 5 до 80 символов», строка не добавилась |
| **Память** | Нажимаю F5 после успешного создания | Добавленная строка исчезла |

**Пояснение к F5:** *Ожидаемо, сервера и БД пока нет. Данные живут только в оперативной памяти браузера.*

## 2. Проверка типов данных и событий

- Для `projectId` использован модификатор `.number`, поэтому в объекте хранится число (например, `2`), а не строка.
- Форма использует `@submit.prevent`, поэтому при нажатии Enter страница не перезагружается, а вызывается функция `onCreate`.
- Валидация проверяет длину строк после `.trim()`.
- Новая запись всегда получает статус `New`.

## 3. Схема данных

Общий массив хранится в `src/taskStore.js`. 
Форма (`TaskNew.vue`) не создает свой массив, а вызывает функцию `addItem` из хранилища.
Список (`TaskList.vue`) читает тот же самый массив `items`.
